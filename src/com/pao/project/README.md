#### 1.1 — Lista cu cel puțin 10 acțiuni / interogări posibile în sistem

- Adaugă o carte nouă
- Înregistrează un cititor nou
- Elimină un cititor
- Catuă cărți după autor
- Caută cărți după categorie
- Verifică disponibilitatea unei cărți
- Împrumută o carte unui cititor
- Returnează o carte
- Afișează istoricul împrumuturilor unui cititor
- Afișează primele 5 cărți cu cele mai multe împrumuturi

#### 1.2 — Lista cu cel puțin 8 tipuri de obiecte din domeniu

`Autor`, `Carte`, `Categorie`, `Cititor`, `Exemplar`, `Imprumut`, `ISBN`, `Penalizare`, `PenalizareDeteriorare`, `PenalizareIntarziere`
